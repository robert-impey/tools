# Logs Deleter Tool

This tool is designed to help manage and clean up various types of log files generated by different internal services, ensuring that only necessary or recent logs are kept, and old, redundant logs are safely removed.

## Core Functionality

The `logs-deleter` tool provides several specialized commands to handle different log formats and retention policies:

1.  **`rsync`**:
    *   Deletes old `.log` files found in the logs directory.
    *   **Retention Logic**: It only deletes logs that do not indicate the presence of copied files (i.e., logs without incremental file lists, or those that appear to be empty after an rsync operation).
    *   *Usage Example:* `logs-deleter rsync --days=30`

2.  **`rerl`**:
    *   Specifically targets logs generated by Robocopy synchronization.
    *   **Retention Logic**: It scans for `.robocopy-synch.log` files and deletes them if they do not show evidence of any files being copied (i.e., the file reports 'Files : 0').
    *   *Usage Example:* `logs-deleter rerl`

3.  **`sweepFrom`**:
    *   Allows targeted cleanup for a single, specific tool's logs (e.g., `sweepFrom --tool=rsync`).
    *   It uses the core log deletion logic (`internal.DeleteFrom`) but restricts the scope to a defined subdirectory within the logs directory.
    *   *Usage Example:* `logs-deleter sweepFrom --tool=rsync --days=7`

4.  **`sweepAll`**:
    *   The broadest cleanup tool. It iterates through all subdirectories within the main logs directory and runs the standard retention policy (`internal.DeleteFrom`) on all of them.
    *   *Usage Example:* `logs-deleter sweepAll`

## General Options & Flags

The tool supports several persistent flags to control global behavior:

*   `--days, --d` (Default: 30): The number of days to keep logs. Files older than this threshold will be considered for deletion by general sweep commands.
*   `--deleteEmpty, --e` (Default: false): If set to `true`, the tool will also consider deleting log files that are completely empty (0 bytes), regardless of their age or content.
*   `--verbose, --v` (Default: false): Enables detailed output, showing which files are being scanned, why they are kept, and confirmation of deletion.
*   `--logsDirectory, --l` (Default: ""): Specifies the root directory containing all the tool-specific log subdirectories.

## Internal Logic (Technical Notes)

The core deletion logic is implemented in `internal/logs_deleter.go` and relies on:

*   **`internal/rerl.go`**: Uses regex matching on lines like `Files : X ...` to check for copy records.
*   **`internal/rsync.go`**: Parses `rsync` specific log headers (`receiving incremental file list`, `sending incremental file list`) to determine if any file transfers were recorded.
*   **`internal/logs_deleter.go`**: Provides the general file system check (`os.Stat` and `time.Before`) combined with optional empty file checks.
